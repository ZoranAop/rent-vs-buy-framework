租房 N 年 vs 贷款 N 年买房 · 财务权衡分析框架

一套参数化的住房决策模型：在相同住房消费、相同月预算假设下，对比「贷款买房」与「租房并把首付与月省用于投资」两种策略的终身净财富、盈亏平衡房价涨幅与敏感性。所有参数可调，结果实时计算。

核心标尺：租金回报率 vs 房贷利率

买房者月流出 = 月供 + 持有 + 房产税；租房者月流出 = 租金（按涨幅增长）。两者均从同一月预算 M 中出。

模型公式
展开公式与计算口径 
【买房方案】
  首付 D=P×首付%；贷款 L=P−D；月利率 mr=rLoan/12；期数 n=X×12
  月供 M=L·mr·(1+mr)^n/((1+mr)^n−1)
  一次性购置成本 = P×buyCostPct%
  持有成本(名义)逐年按通胀增长；房产税=propTax%×当年房价/年
  卖房成本 = 房产终值×sellCostPct%
  房产终值 = P×(1+houseG)^X
  买家毛资产 = 房产终值
  买家净收益 = 房产终值 − 购置 − Σ持有 − Σ房产税 − 卖房成本

【租房方案】
  组合期初=D；每月：组合=组合×(1+invRet/12)+(M−当月租金)；租金按 rentG 月化增长
  组合终值(税前)=组合期末
  投资税 = max(0, 组合−累计投入)×invTax%
  租房净收益 = 组合终值 − 投资税

【盈亏平衡门槛 g*】  (按所选口径)
  净收益口径：求 g* 使 买家净收益(g*) = 租房净收益
  毛资产口径：求 g* 使 P×(1+g*)^X = 组合终值
  ⇒ 房价年化涨幅>g* 买房赢；<g* 租房赢

【实际购买力】
  买房实际支出 = D + Σ_t (M+持有_t+房产税_t)/(1+印钞)^(t/12)
  租房实际支出 = Σ_t 租金_t/(1+通胀)^(t/12)
  终值实际 = 资产/(1+通胀)^X

说明：默认开「净收益」口径，与「扣持有成本」的保守视角一致；切到「毛资产」可看不扣成本的结果。所有数字单位均为"万元"。模型为确定性框架，投资回报率为外生常数，未含收入增长与资产波动；扩展方向见 README。
