运行命令：
```bash
python rent_vs_buy_model.py --basis net
python rent_vs_buy_model.py --basis gross
```

## 判读

- 两种口径下，**房价年化涨幅需超过约 3.2%，买房才不输给租房定投**。
- 租金回报率 1.667% < 房贷利率 3% → 持有房产现金流为负，若房价不涨，买房处于劣势。
- 切换口径时，胜者与 `g*` 同向变化但幅度不同：净收益口径更保守（扣税后租房优势收窄）。
